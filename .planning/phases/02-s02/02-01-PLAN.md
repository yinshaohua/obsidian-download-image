<objective>
Create release verification script that audits submission readiness
</objective>

<context>
Phase: 02 (s02) — Milestone: Submit plugin to Obsidian community catalog

Create `scripts/verify-release.mjs` — a standalone Node.js script that programmatically checks whether the repository is ready for an Obsidian community plugin submission. The script reads `manifest.json`, `package.json`, `versions.json`, and checks for release asset files, then reports pass/fail for each check and exits non-zero if any check fails.

This is the automated half of the slice deliverable. The checklist document (T02) will reference this script as the preflight step.
</context>

<must_haves>

- Script checks version parity across manifest.json, package.json, and versions.json
- Script flags plugin IDs starting with `obsidian-` as a blocker/warning
- Script checks required manifest fields, description length, and empty optional fields
- Script checks release asset file presence at repo root
- Script uses only Node.js built-ins (no new dependencies)
- `package.json` has a `verify-release` script entry
- Exit code is 0 when no errors, 1 when errors found

</must_haves>
