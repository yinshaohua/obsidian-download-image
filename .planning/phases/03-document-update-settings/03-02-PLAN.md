  <behavior>
**replacer.test.ts — isInsideCodeBlock:**
- Position inside fenced code block (```) returns true
- Position inside tilde fenced block (~~~) returns true
- Position outside code blocks returns false
- Position inside inline code (backticks) returns true
- Position in normal text adjacent to code block returns false

**replacer.test.ts — buildReplacementMap:**
- Markdown image `![alt](https://example.com/img.png)` with ok result produces replacement `![alt](local/path.png)`
- Wiki image `![[https://example.com/img.png]]` with ok result produces `![[local/path.png]]`
- HTML img `<img src="https://example.com/img.png">` with ok result produces `<img src="local/path.png">`
- Failed result (status: 'failed') produces NO replacement entry
- Image reference inside fenced code block produces NO replacement entry
- Image reference inside inline code produces NO replacement entry
- Multiple occurrences of same URL in normal text produce multiple replacement entries
- Replacements are sorted by index descending

**replacer.test.ts — applyReplacements:**
- Single replacement at known index produces correct output
- Multiple replacements applied correctly (end-to-start order)
- Empty replacements array returns content unchanged

**downloader.test.ts — deriveFilenameWithStrategy:**
- strategy='original' for HTTP URL returns same as deriveFilenameFromUrl
- strategy='timestamp' produces filename matching /^\d{8}-\d{6}-.+/
- strategy='hash' produces filename matching /^[a-z0-9]{8}\.\w+$/
- strategy='hash' with same buffer content produces same filename (content-addressable)
- strategy='hash' with different buffer content produces different filename
- strategy='original' for base64 returns same as deriveFilenameFromBase64
  </behavior>
