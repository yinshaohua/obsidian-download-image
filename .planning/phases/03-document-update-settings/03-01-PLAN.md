```typescript
export function deriveFilenameWithStrategy(
  url: string,
  contentType: string | undefined,
  buffer: ArrayBuffer,
  strategy: NamingStrategy,
  isBase64: boolean,
  mimeType?: string
): string {
  switch (strategy) {
    case 'timestamp': {
      // D-06: timestamp prefix format YYYYMMDD-HHmmss
      const now = new Date();
      const ts = now.getFullYear().toString()
        + String(now.getMonth() + 1).padStart(2, '0')
        + String(now.getDate()).padStart(2, '0')
        + '-'
        + String(now.getHours()).padStart(2, '0')
        + String(now.getMinutes()).padStart(2, '0')
        + String(now.getSeconds()).padStart(2, '0');
      const base = isBase64
        ? deriveFilenameFromBase64(mimeType ?? 'image/png')
        : deriveFilenameFromUrl(url, contentType);
      return ts + '-' + base;
    }
    case 'hash': {
      // D-07: content-addressable — short hash of actual file bytes
      let h = 0;
      const view = new Uint8Array(buffer);
      for (let i = 0; i < view.length; i++) {
        h = ((h << 5) - h + view[i]!) | 0;
      }
      const hashStr = Math.abs(h).toString(36).padStart(8, '0');
      const ext = isBase64
        ? (MIME_TO_EXT[(mimeType ?? '').toLowerCase()] ?? 'png')
        : (MIME_TO_EXT[(contentType?.split(';')[0]?.toLowerCase().trim()) ?? ''] ?? 'png');
      return hashStr + '.' + ext;
    }
    case 'original':
    default:
      // D-05: current deriveFilenameFromUrl/deriveFilenameFromBase64 logic
      return isBase64
        ? deriveFilenameFromBase64(mimeType ?? 'image/png')
        : deriveFilenameFromUrl(url, contentType);
  }
}
```

```typescript
import { DownloadResult } from './downloader';
```

**Function 1: `isInsideCodeBlock(content: string, position: number): boolean`** (per D-09)
- Checks if a character position is inside a fenced code block (``` or ~~~) or inline code (backtick pairs)
- For fenced blocks: scan from start, toggle a `inFencedBlock` boolean each time a line starts with ``` or ~~~
- For inline code: check if the position is between an odd-numbered backtick and the next one on the same line
- Export this function for testability

**Function 2: `buildReplacementMap(content: string, results: DownloadResult[]): Array<{ from: string; to: string; index: number }>`**
- For each result where `status === 'ok'` (per D-12), find ALL occurrences of `result.ref.original` in `content`
- For each occurrence, check `isInsideCodeBlock(content, occurrenceIndex)` — skip if true (per D-09)
- For the replacement string:
  - If `result.ref.type === 'wiki'`: replace with `![[${result.localPath}]]`
  - If `result.ref.type === 'http'` and original starts with `<img`: replace with `<img src="${result.localPath}"` preserving other attributes from original
  - If `result.ref.type === 'http'`: replace with `![${result.ref.alt ?? ''}](${result.localPath})`
  - If `result.ref.type === 'base64'`: replace with `![${result.ref.alt ?? ''}](${result.localPath})`
- Return array sorted by `index` descending (so replacements from end-of-document first, preserving earlier indices)
- Export this function

**Function 3: `applyReplacements(content: string, replacements: Array<{ from: string; to: string; index: number }>): string`**
- Iterate over replacements (already sorted descending by index)
- For each: `content = content.slice(0, r.index) + r.to + content.slice(r.index + r.from.length)`
- Return modified content
- Export this function

2. Replace the command handler body inside `editorCallback` with the full pipeline:

```typescript
editorCallback: async (editor: Editor, view: MarkdownView) => {
  const content = editor.getValue();
  const refs = extractImages(content);
  if (refs.length === 0) {
    new Notice('No remote images found in current note');
    return;
  }

  const notePath = view.file?.path ?? '';

  // D-01: real-time progress Notice — reuse single Notice instance
  const progressNotice = new Notice('Downloading images...', 0);

  try {
    const results = await downloadImages(refs, this.app, notePath, {
      concurrency: this.settings.concurrency,
      namingStrategy: this.settings.namingStrategy,
      onProgress: (completed, total) => {
        // D-01: update the Notice message in-place
        progressNotice.setMessage(`Downloading ${completed}/${total} images...`);
      },
    });

    // Hide progress notice
    progressNotice.hide();

    // Deduplicate by URL for accurate counts
    const seen = new Set<string>();
    const uniqueResults: typeof results = [];
    for (const r of results) {
      if (!seen.has(r.ref.url)) {
        seen.add(r.ref.url);
        uniqueResults.push(r);
      }
    }

    const ok = uniqueResults.filter(r => r.status === 'ok').length;
    const failedResults = uniqueResults.filter(r => r.status === 'failed');

    // Console logging (same as before)
    console.log(`[download-image] ${refs.length} refs found, ${uniqueResults.length} unique URLs, ${ok} ok, ${failedResults.length} failed`);
    for (const r of uniqueResults) {
      if (r.status === 'ok') {
        console.log(`  OK ${r.ref.url} -> ${r.localPath}`);
      } else {
        console.warn(`  FAIL ${r.ref.url}: ${r.error}`);
      }
    }

    // DOC-01, DOC-02, D-11: Replace URLs in document via single editor.transaction
    if (ok > 0) {
      const currentContent = editor.getValue();
      const replacements = buildReplacementMap(currentContent, results);
      if (replacements.length > 0) {
        const newContent = applyReplacements(currentContent, replacements);
        // D-11: single transaction = single undo step
        editor.transaction({
          changes: [{
            from: { line: 0, ch: 0 },
            to: { line: editor.lineCount(), ch: 0 },
            text: newContent,
          }],
        });
      }
    }

    // D-02: concise summary notice
    const dupes = refs.length - uniqueResults.length;
    new Notice(
      `Downloaded ${ok} image(s)${failedResults.length > 0 ? `, ${failedResults.length} failed (see console)` : ''}` +
      (dupes > 0 ? ` (${dupes} duplicate refs skipped)` : '')
    );

  } catch (err) {
    progressNotice.hide();
    console.error('[download-image] Unexpected error:', err);
    new Notice('Image download failed unexpectedly. Check console for details.');
  }
}
```

Note on `editor.transaction`: The Obsidian `Editor.transaction()` method takes `{ changes: EditorChange[] }`. Each `EditorChange` has `{ from: EditorPosition, to: EditorPosition, text: string }`. By replacing the entire document content in a single change within a single transaction, it ensures one Ctrl+Z undoes all replacements (per D-11, DOC-02).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote URL -> local path in document | Downloaded content path is written into the Markdown document |
| user settings -> download behavior | User-configurable concurrency and naming affect runtime behavior |
| document content -> replacement logic | Document text is parsed for replacement targets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | src/replacer.ts | mitigate | Only replace exact `ref.original` strings found by the parser — never construct replacement targets from untrusted input. Use index-based replacement (not regex) to avoid injection. |
| T-03-02 | Information Disclosure | src/settings.ts | accept | Settings (naming strategy, concurrency) contain no secrets. Stored via Obsidian's standard plugin data API which writes to local disk. |
| T-03-03 | Denial of Service | src/downloader.ts | mitigate | Concurrency capped at max 10 via slider range. Existing 30s per-image timeout prevents hung downloads from blocking indefinitely. |
| T-03-04 | Spoofing | src/replacer.ts | mitigate | `localPath` in DownloadResult is produced by Obsidian's `vault.createBinary` / `fileManager.getAvailablePathForAttachment` — trusted vault API output, not user-supplied. Path is vault-relative, cannot reference files outside vault. |
| T-03-05 | Tampering | src/main.ts | mitigate | Re-read `editor.getValue()` immediately before replacement (not using stale content from before download). This prevents replacing stale content if user edited during download. |
</threat_model>
