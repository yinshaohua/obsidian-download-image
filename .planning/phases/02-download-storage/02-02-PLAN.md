    **isValidImageContentType (D-08):**
    - Returns true for 'image/png', 'image/jpeg', 'image/gif', 'image/webp', 'image/svg+xml'
    - Returns true for 'application/octet-stream' (CDN fallback)
    - Returns true for 'image/png; charset=utf-8' (with parameters)

    **deriveFilenameFromUrl (D-01, D-02):**
    - 'https://example.com/photo.png' -> 'photo.png'
    - 'https://example.com/photo.png?token=abc&w=100' -> 'photo.png' (strips query)
    - 'https://example.com/photo.png#section' -> 'photo.png' (strips fragment)
    - 'https://cdn.example.com/a1b2c3d4e5f6' with contentType 'image/jpeg' -> filename ends with '.jpg' (extensionless path + Content-Type inference)
    - 'https://cdn.example.com/a1b2c3d4e5f6' without contentType -> filename ends with '.png' (fallback)
    - 'https://example.com/' with contentType 'image/webp' -> filename starts with 'image-' and ends with '.webp' (empty path segment, D-02 timestamp fallback)
    - 'https://example.com/ab' without contentType -> filename starts with 'image-' (short segment < 3 chars triggers fallback)
    - 'https://example.com/photo.jpeg' -> 'photo.jpeg' (preserves original extension)

    **deriveFilenameFromBase64 (D-03):**
    - 'image/png' -> matches pattern /^base64-\d+\.png$/
    - 'image/jpeg' -> matches pattern /^base64-\d+\.jpg$/
    - 'image/gif' -> matches pattern /^base64-\d+\.gif$/
    - 'unknown/type' -> matches pattern /^base64-\d+\.png$/ (fallback to png)

    **decodeBase64Image (D-13, D-14):**
    - Valid PNG data URI: returns object with mimeType 'image/png' and buffer is ArrayBuffer
    - Valid JPEG data URI: returns mimeType 'image/jpeg'
    - Decoded buffer has correct byte length (known base64 input -> known output size)
    - Throws on invalid data URI (no comma separator)
    - Throws on empty/undefined input parts
    - Does NOT use Node.js Buffer (D-14 compliance — test file itself should use atob for comparison)
